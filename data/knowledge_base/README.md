# Knowledge Base Structure

Use this folder as the curated startup knowledge base for StartupSpark AI.

## Folder Layout

- `common/` for shared startup concepts, frameworks, and general business knowledge
- `healthcare_ai/` for healthcare and medical AI sources
- `fintech/` for banking, payments, lending, and finance sources
- `edtech/` for education technology sources
- `agritech/` for agriculture and farm-tech sources
- `cybersecurity/` for security, compliance, and threat-intelligence sources

## Recommended File Types

- PDF reports
- case studies
- whitepapers
- public blog posts saved as text or PDF
- competitor notes
- manually curated summaries

## Required Metadata

For every file you add, keep track of:

- domain
- source name
- URL
- publish date
- document type
- trust level
- summary

## Suggested File Naming

Use lowercase names with underscores:

- `healthcare_ai_market_report_2025.pdf`
- `fintech_competitor_analysis.md`
- `edtech_user_pain_points.txt`

## Intake Rule

Put general startup knowledge in `common/` and domain-specific material in the matching domain folder. When in doubt, save the file in the domain folder and tag it with metadata.
